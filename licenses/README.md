# Binary releases

OLEDHero and PySide6/Qt are distributed under GPLv3.

Publish the complete corresponding source with each binary release, including
OLEDHero's build script and lock file and the source for bundled GPL components
such as Qt, PySide6, and Shiboken6. Package the complete `dist/oledhero.dist`
directory in the installer and include the supplied license notices.
